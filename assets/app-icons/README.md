App icons drawn for apps that Numix Square has none for (Strata, GPU Screen
Recorder, hyprmoncfg, the CachyOS tools, Rofi, Shelly...), in its style: a
flat gradient tile with a white glyph. The installer copies them into
~/.local/share/icons/Numix-Square/{48,48@2x}/apps; each file is named after
the Icon= its app's .desktop entry asks for.
